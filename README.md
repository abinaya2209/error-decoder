# 🐛 Error Decoder

An AI-powered tool that converts raw programming error messages and stack traces into beginner-friendly explanations and fixes.

## Features
- Supports Python, JavaScript, Java and more
- Explains what caused the error in plain English
- Suggests the most likely fix
- Tips to avoid the error in future

## Tech Stack
- Frontend: React (Vite)
- Backend: Flask (Python)
- AI: Groq LLM API (LLaMA 3)

## How to Run
1. Clone the repo
2. Backend: `cd backend` → `pip install -r requirements.txt` → `python server.py`
3. Frontend: `cd frontend` → `npm install` → `npm run dev`
